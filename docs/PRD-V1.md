# AI短剧导演 V1 — PRD

## 1. 产品定位

AI短剧导演 V1 是一个面向完全没有短剧制作经验用户的引导式创作系统。

不是工具箱，而是“AI导演助手 + 流程向导”。

用户不需要知道：
- 剧本怎么写
- 分镜怎么拆
- Prompt 怎么写
- 视频模型怎么选

系统需要始终告诉用户：
1. 你现在在哪一步
2. 当前需要做什么
3. 下一步是什么

---

## 2. 目标用户

典型用户：
- 从没做过短剧
- 不懂编剧结构
- 不懂镜头语言
- 不懂 AI 生图/视频 Prompt
- 只知道“我想做 AI 短剧”

---

## 3. 首页

主标题：
**把一个想法，变成第一部 AI 短剧**

主按钮：
**开始制作第一部短剧**

入口：
1. 我有一个故事想法
2. 我不知道拍什么
3. 我有小说 / 文案 / 故事

下方展示“我的项目”。

---

## 4. 项目流程

固定八步：

1. 故事
2. 人物
3. 剧本
4. 分镜
5. 画面
6. 视频
7. 剪辑
8. 成片

顶部显示进度，例如：
**3 / 8 — 剧本**

---

## 5. Step 1：故事

输入方式：
- 用户直接输入想法
- 系统推荐 5–10 个方向
- 粘贴已有文本

系统输出：
- 标题
- 一句话故事
- 开场钩子
- 核心冲突
- 冲突升级
- 第一次反转
- 尾钩

### Story Health Check
检查：
- 前 3 秒钩子
- 明确冲突
- 信息差
- 反转
- 尾钩/追下一集动机

状态：
- 通过
- 需优化

提供：
**AI 帮我优化**

---

## 6. Step 2：人物

系统自动生成角色卡。

字段：
- 姓名
- 年龄
- 性别
- 外貌
- 发型
- 服装
- 气质
- 性格
- 核心欲望
- 隐藏秘密
- 说话方式
- 视觉关键词

操作：
- 确认
- 换一种感觉
- 自己修改

确认后状态变为：
**角色已锁定**

后续 Prompt 始终引用锁定后的角色设定。

---

## 7. Step 3：单集剧本

默认目标：
- 60 秒
- 10–15 个镜头
- 竖屏短视频节奏

对用户展示“人话版”剧本，不展示影视行业复杂格式。

每段包含：
- 画面
- 动作
- 台词
- 情绪
- 大致时长

---

## 8. Step 4：自动分镜

生成 Shot 列表。

每镜字段：
- 镜头编号
- 画面内容
- 时长
- 景别
- 人物
- 主动作
- 情绪
- 导演说明

导演说明重点：
- 是否需要说话
- 是否需要复杂动作
- 是否建议固定镜头
- AI 生成风险提醒

原则：
**每镜尽量只聚焦一个主动作。**

---

## 9. Step 5：画面 Prompt

系统内部自动组合：
人物身份 + 外貌 + 服装 + 场景 + 构图 + 灯光 + 镜头语言 + 风格

前端默认只显示：
**生成这一镜**

高级区域可展开：
- 正向 Prompt
- Negative Prompt
- 角色引用
- 画面参数

---

## 10. Step 6：视频 Prompt

由当前镜头图 + 动作生成视频 Prompt。

必须包含：
- 主动作
- 表情变化
- 镜头运动
- 背景稳定要求
- 禁止项

示例禁止项：
- 不要变脸
- 不要改变服装
- 不要新增人物
- 不要出现多余肢体
- 不要复杂大幅动作

V1 先提供可复制 Prompt。

---

## 11. Step 7：剪辑

自动输出：
- 时间轴
- 每镜时长
- 台词
- 字幕
- BGM 建议
- 音效
- 转场建议
- 封面标题
- 发布标题
- 发布文案
- 下一集预告

---

## 12. Step 8：成片 / 导出

导出内容：
- 故事设定
- 人物卡
- 剧本
- 分镜表
- 生图 Prompt
- 视频 Prompt
- 剪辑时间轴
- 字幕
- 标题
- 发布文案

V1 导出：
- Markdown
- JSON

## 13. 内置 Demo

项目：
**《丈夫每月给陌生女人2万元》**

### 林妍
32 岁，中国女性，知性克制，黑色中长发，米白针织衫。

### 周川
35 岁，中国男性，温和可靠，深灰居家服，隐瞒五年前的秘密。

### 沈岚
42 岁，中国女性，成熟克制，略显疲惫。

### 第一集核心
林妍发现丈夫连续五年，每个月都给一个陌生女人转 2 万元。
第一笔转账发生在他们结婚第二天。

尾段：
沈岚在电话中说：
“你老公没告诉你，五年前你为什么能活下来吗？”

浴室门打开，周川站在身后：
“你给她打电话了？”

黑屏。

## 15. V1 非目标

暂不做：
- 自动发布抖音
- 自动生成 100 集
- 复杂角色关系图
- 自动剪辑成片
- Seedance / 可灵 / 即梦 API 强绑定
- 团队协作
- 复杂数据分析

---

## 16. 验收标准

完全不懂短剧的用户：
- 不看教程也知道下一步
- 可以完整完成 Demo
- 10–20 分钟内拿到第一集制作包
- 所有关键页面均有唯一主 CTA
- 能复制每镜生图 / 视频 Prompt
- 能导出 Markdown / JSON
